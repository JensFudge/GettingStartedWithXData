# Getting Started with XData - Links and Resources

This file contains links and additional resources referenced in *Getting Started with XData*.

Keeping the links here makes them easier to use from the electronic source code and allows the list to be updated if resources move or change.

## Getting Started with XData

### The Book

*Getting Started with XData* by Jens Fudge takes you step by step through the development of the XData application contained in this repository.


[Getting Started with XData on Amazon](https://www.amazon.com/dp/8797729221)
*The link uses Amazon.com. Replace `.com` with your preferred Amazon marketplace if needed.*

### Source Code

The complete source code accompanying the book is available in
this repository.

https://github.com/JensFudge/GettingStartedWithXData


## TMS Software

### TMS Dashboard

The TMS Dashboard is used to download and manage TMS products, including the components required for XData.

https://www.tmssoftware.com/site/tmsdashboard.asp

## Swagger

### Swagger

Swagger provides tools and specifications for describing and working with REST APIs. In the book, XData's built-in Swagger support is used to explore and test the API while it is being developed.

https://swagger.io/

## XData Documentation

### XData Documentation

The official TMS XData documentation. This is the main reference for XData and covers installation, server configuration, services, authentication, clients, database connectivity, and other XData features.

https://doc.tmssoftware.com/biz/xdata/

### Server Memory Management

The official XData documentation describing how XData manages the lifetime of objects on the server, including result objects and objects registered with the request context.

https://doc.tmssoftware.com/biz/xdata/guide/service.html#server-memory-management

### Client Memory Management

The official XData documentation describing object ownership and memory management when using `TXDataClient`.

https://doc.tmssoftware.com/biz/xdata/guide/txdataclient.html#client-memory-management

## Authentication and JWT

### token.dev

A browser-based JWT viewer that can be used to inspect the header and payload of a JSON Web Token.

The book uses it only as a demonstration tool. Do not paste tokens containing sensitive information into third-party services.

https://www.token.dev
